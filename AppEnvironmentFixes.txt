Environment variables some Flatpaks need under Flatdroid.

Set them per app: turn on Settings > Developer options, open the app's settings, and enter
them under Launch > Environment variables, one NAME=value per line. They apply at the
app's next launch.

# VLC (org.videolan.VLC)
```
VLC_PLUGIN_PATH=/app/lib/vlc/plugins
VLC_DATA_PATH=/app/share/vlc
```

# Firefox (org.mozilla.firefox)
Without it every tab crashes: the tab processes find no usable font in Firefox's content
sandbox (`[GFX1]: no fonts`, then a crash in gfxFontGroup::GetDefaultFont). It turns off
Firefox's own sandbox for web content; Firefox shows a warning bar about it.
```
MOZ_DISABLE_CONTENT_SANDBOX=1
```
